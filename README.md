# Accessibility Audit & Fix Agent

Autonomous WCAG 2.2 engineer for Claude Code. It audits your real Angular, React and Vue source code, fixes the root causes, re-runs your validation (build, tests, axe) and delivers an honest before/after report.

## Features
- Layered audit beyond linters: semantics, keyboard, focus, forms, ARIA, contrast, reflow, motion
- Fixes root causes once, preserving your design and component APIs
- Two modes: audit-only and audit + fix
- Honest reporting, with items needing manual screen reader checks clearly marked
